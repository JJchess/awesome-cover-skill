三门课统一视觉体系：现代教育科技风、扁平 + 轻立体、留白充足、左侧主标题区右侧主视觉区，便于后期叠加中文课程名。所有 prompt 为英文，比例 16:10。

Color palette of Python blue (#3776AB) and warm yellow (#FFD43B) accents on a soft off-white background with a faint dotted grid. Bright, optimistic, beginner-friendly mood, crisp vector-style rendering, soft ambient lighting, high detail, professional EdTech branding, no text, no letters, no watermark.

### 通用使用提示
- 三门课共用配色逻辑与构图框架（左标题 / 右主视觉、留白、扁平轻立体），并排时视觉统一，可作为同一课程系列。
- prompt 内已加 `no text, no letters` 以避免 AI 生成乱码文字，标题建议后期排版叠加。
- 如需更强系列感，可固定背景底色（如统一 off-white）后仅替换主视觉与主色。
