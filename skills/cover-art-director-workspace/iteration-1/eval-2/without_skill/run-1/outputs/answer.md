# Nano Banana 文生图 Prompt — 互动场景产品封面图

## 场景说明
多个 AI Agent 协作完成一次市场调研，有清晰的角色分工与多智能体讨论。下面是为 Nano Banana 准备的英文 prompt。

---

## 主 Prompt（推荐）

```
A wide cinematic cover illustration for an interactive AI product, depicting a team of multiple AI agents collaborating on a market research project. Several distinct stylized AI agent characters — each glowing in a different signature color (electric blue, warm orange, teal green, soft purple) — are gathered around a luminous holographic round table in a sleek futuristic workspace. Each agent has a unique visual role: one with a magnifying-glass data-scanner motif analyzing charts, one surrounded by floating survey forms and customer icons, one orchestrating and pointing like a coordinator, one assembling glowing bar charts and pie graphs into a final report. Translucent speech-bubble connectors, dotted data streams, and light beams flow between the agents to show active discussion and idea exchange. Above the table floats a shared holographic dashboard with market trends, line graphs, and growth arrows. Clean modern tech aesthetic, semi-flat 3D illustration with soft volumetric lighting, subtle particle effects, balanced negative space at the top for a title. Cohesive cool-toned palette with vibrant accent highlights, depth of field, professional and inviting mood. 16:9 aspect ratio, high detail, polished marketing-quality.
```

---

## 关键元素拆解（便于调整）

- **多智能体 + 角色分工**：4 个用不同颜色和图标区分的 agent（数据分析 / 用户调研 / 协调编排 / 报告生成），一眼能看出"分工"。
- **协作与讨论**：发光的对话气泡连接线、流动的数据流、光束，表达"多智能体讨论"。
- **市场调研主题**：全息仪表盘、图表、增长曲线、调研问卷与客户图标。
- **产品封面属性**：16:9、顶部留白放标题、营销级精致度、现代科技审美。

---

## 可选风格变体

**A. 更温暖、亲和的扁平插画风（适合 toB 产品官网）**
```
Replace "semi-flat 3D illustration" with "modern flat vector illustration with rounded friendly shapes", keep the warm pastel-on-cool palette, soft gradients, minimal shadows, approachable corporate-tech look.
```

**B. 更具未来感、酷炫的氛围（适合发布会主视觉）**
```
Replace the workspace with a dark sci-fi command center, neon holographic interfaces, dramatic rim lighting, deep navy background, glowing circuit textures, high-contrast cinematic mood.
```

**C. 拟人化机器人角色（如果希望 agent 更具体可爱）**
```
Render each AI agent as a distinct friendly humanoid robot with a different accent color and a role-specific tool (chart tablet, survey clipboard, conductor's baton, report folder), expressive and characterful, Pixar-like soft rendering.
```

---

## 使用提示
- 若生成结果中 agent 数量不稳定，可在 prompt 中把 "Several" 明确改为 "exactly four"。
- 顶部留白处可后期叠加产品名/标题，prompt 已预留 "balanced negative space at the top for a title"。
- 想要不同比例时，把 `16:9` 改为 `3:2`（横版海报）或 `1:1`（社媒方图）。
