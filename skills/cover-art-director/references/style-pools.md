## 全局

三类通用，每条 prompt 都要带上。

**构图原型（与各自媒介自由组合）**
左主体右留白 · 满版场景 · 居中带边距 · 对角动势 · 网格/三联 · 微距特写 · 俯视平铺

**平台 DNA 片段（粘进每条 prompt）**
> art-directed, hand-crafted editorial quality; single consistent light source; intentional asymmetry; restrained palette of 2–3 anchored hues plus a neutral; matte finish with subtle film grain; clean geometric structure; generous negative space; 16:10.

**avoid 段（粘进每条 prompt）**
> no glowing neon circuit boards, no hexagon grids, no matrix code rain, no tech-blue-gradient-on-black, no chrome spheres, no robot heads or glowing brains, no plastic glossy 3D render, no fake bokeh everywhere, no lens flare spam, no floating UI panels, no centered symmetric hero blob, no cluttered composition, no garbled or misspelled text.

## 云课堂 Cloud Classroom

**关键词**：课程 / tutorial / 学习路径 / 结构化讲义 / 被引导的学习过程
**调性**：温暖、清晰、有结构、令人想靠近、聪明而不冰冷。这是"被人引导着拾级而上"的感觉。

**色族（暖、平静，每条取 2–3 个锚定色 + 中性）**
- 米白 + 琥珀 + 墨 (cream / amber / deep ink)
- 鼠尾草绿 + 暖白 + 陶土橙 (sage green / warm white / terracotta)
- 雾霾蓝 + 沙色 + 珊瑚 (dusty blue / sand / coral)
- 燕麦 + 黄铜 + 森林绿 (oatmeal / brass / forest green)

**媒介（轮换）**
1. 现代编辑插画 modern editorial illustration（扁平+纹理）
2. 层叠纸艺 / 折纸 diorama layered paper-craft, soft 3D
3. 等距结构化场景 isometric structured scene（拾级而上的台阶/平台）
4. 手绘批注式"讲义即艺术" hand-annotated diagram-as-art
5. 孔版印刷质感 risograph / textured print
6. 柔光小景模型 soft clay/diorama miniature

**母题**：蜿蜒的路径与地图、层叠的台阶、概念之间连成的星座、被重新想象的书本、积木与构件、引导的光/灯塔。

**范例**
- *(等距 + 鼠尾草绿)* `Editorial-quality course cover, art-directed and hand-crafted. An isometric staircase of translucent terraces ascending toward a soft glow, small markers along the way — a guided learning path through data structures. Isometric structured scene, soft daylight from upper-left, one light source, matte finish, gentle grain. Composition: centered with margins, clean negative space at top for a title. Palette: sage green, warm white, terracotta accents. 16:10. Avoid: [global avoid].`
- *(纸艺 + 雾霾蓝)* `... layered paper-craft diorama of an open landscape unfolding like a textbook into hills and paths, lanterns marking stages ... dusty blue, sand, coral accents; lower-left negative space reserved for title ...`
- *(编辑插画 + 米白琥珀)* `... flat editorial illustration with paper texture, a constellation of linked concept-nodes forming a gentle map of a curriculum ... cream, amber, deep ink ...`

## 代码实验室 Code Lab

**关键词**：JupyterLab / notebook / code / data / experiment / computational workspace
**调性**：精确、动手、实验性、干净、专注。是"设计工作室遇上科学实验室"，**绝不是**霓虹电路板那套技术 cliché。更冷、更有网格秩序，可以有一个电光强调色。

**色族（偏冷、克制，可带一个电光强调色）**
- 石板灰 + 米白 + 电光蓝 (slate / off-white / electric blue)
- 墨蓝 + 青柠强调 (ink navy / lime accent / paper)
- 石墨 + 暖白 + 信号橙 (graphite / warm white / signal orange)
- 深青 + 纸色 + 一点品红 (deep teal / paper / magenta spark)

**媒介（轮换）**
1. 优雅的数据可视化即艺术 data-visualization-as-art（图表当雕塑）
2. 等距工作台/书桌场景 isometric workspace desk
3. 蓝图/示意图线稿 blueprint / schematic linework
4. 材质/微距研究 material or macro study（纸、网格、墨）
5. 干净的暗色模式编辑设计 clean dark-mode editorial
6. 模块化构件 modular blocks / typographic technical poster

**母题**：notebook 的 cell、被雕塑化的图表与曲线、流动的数据、网格与坐标、被重新想象的实验器皿、可组合的模块。

**范例**
- *(数据可视化 + 石板电光蓝)* `Editorial-quality cover for a computational notebook, art-directed and hand-crafted. Elegant data-visualization-as-art: a smooth volatility curve rising as a sculpted ribbon over a faint grid, small plotted nodes like an experiment in progress. Clean studio light, one source, matte finish, subtle grain, precise geometric structure. Composition: subject on the right, negative space on the left for a title. Palette: slate, off-white, one electric-blue accent. 16:10. Avoid: [global avoid].`
- *(等距工作台 + 石墨信号橙)* `... isometric workspace desk with a notebook, modular blocks and a single plotted chart, tactile and tidy ... graphite, warm white, signal-orange accent ...`
- *(蓝图线稿 + 墨蓝青柠)* `... blueprint schematic linework of a data pipeline reimagined as elegant plumbing of nodes and flows ... ink navy, paper, lime accent ...`

> 注意：代码实验室最容易滑进 AI 味（霓虹/矩阵/电路板）。一旦出现这些苗头，改走"实验室器皿 + 数据图表雕塑 + 网格"的实体、可触摸方向。

## 互动场景 Interactive Scenarios

**关键词**：多个 AI Agent 的对话环境 / 多角色协作 / 多智能体讨论 / 任务分工
**调性**：活泼、协作、对话感、有能量、带点舞台戏剧性。比另外两类更鲜亮、对比更强——但仍然要和谐，不是花。

**色族（更鲜亮但受控，双色调/宝石色，2–3 个强色）**
- 品红 + 橘 + 米白 (magenta / tangerine / cream)
- 钴蓝 + 珊瑚 + 柔黄 (cobalt / coral / soft yellow)
- 紫罗兰 + 青 + 暖光 (violet / teal / warm light)
- 祖母绿 + 梅子紫 (emerald / plum / off-white)

**媒介（轮换）**
1. 抽象的"Agent 角色形体"在对话 abstract character/agent shapes in dialogue
2. 节点星座（节点即角色）network/constellation of nodes-as-characters
3. 舞台调度 + 聚光 theatrical staging with spotlights
4. 大胆几何拼贴 bold geometric collage
5. 动势插画 dynamic motion illustration
6. 俏皮的 3D 角色小队 playful 3D cast of characters（哑光、非塑料）

**母题**：对话泡/对话形体、相连的人形、网络、角色/面具、交换与流动、舞台与分工。

**范例**
- *(节点星座 + 钴蓝珊瑚)* `Editorial-quality cover for a multi-agent collaboration scene, art-directed and hand-crafted. A lively constellation of distinct character-nodes connected by flowing dialogue lines, each node a different shape and role, energy moving between them — multi-agent discussion and task division. Bold but harmonized, single light source, matte finish, subtle grain. Composition: diagonal dynamic, negative space upper-right for a title. Palette: cobalt, coral, soft yellow. 16:10. Avoid: [global avoid].`
- *(舞台聚光 + 紫罗兰青)* `... theatrical staging: several abstract agent-figures arranged on a stage under warm spotlights, mid-conversation, roles distinguished by silhouette ... violet, teal, warm light ...`
- *(几何拼贴 + 品红橘)* `... bold geometric collage of speech forms and connected figures dividing tasks, playful and dynamic ... magenta, tangerine, cream ...`

## 三类如何各不相同

把这张对照表记牢——这是"产品间不同质化"的保证：

| | 调性 | 色温 | 标志媒介 |
|---|---|---|---|
| **云课堂** | 温暖、平静、引导 | 暖 | 纸艺 diorama、编辑插画、等距台阶 |
| **代码实验室** | 精确、动手、秩序 | 冷 + 单电光强调 | 数据可视化雕塑、蓝图线稿、工作台 |
| **互动场景** | 活泼、对话、戏剧 | 鲜亮、高对比 | 节点星座、舞台聚光、几何拼贴 |

统一感不来自颜色（颜色刻意多元），而来自三类共享的：哑光手工质感、单一光源、几何骨架、留白、编辑级成片标准。三者放在一起，应当像同一家品牌做的、但分属三个系列的封面。
